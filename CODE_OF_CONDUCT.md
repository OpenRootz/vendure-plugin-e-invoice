# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be respectful and constructive, assume good intent, and keep discussions about the work. Harassment,
insults, discriminatory language and publishing other people's private information are not tolerated in issues,
pull requests, discussions or any other project space.

## Reporting

If you experience or witness unacceptable behaviour, report it to the maintainers privately through
[GitHub's reporting tools](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
or by opening a private
[security advisory](https://github.com/OpenRootz/vendure-plugin-e-invoice/security/advisories/new) marked as a
conduct report. All reports are handled confidentially.

Maintainers may remove, edit or reject comments, commits, code, issues and other contributions that violate this
code of conduct, and may temporarily or permanently ban contributors, following the enforcement guidelines of the
Contributor Covenant.
